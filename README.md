# Interview Platform

🎯 **AI Mock Interview Platform**
A smart interview preparation platform that helps users practice and improve interview skills using AI-powered feedback and resume analysis.

---

## 🚀 Features

* 🤖 **AI Interview Generator**
  Generates personalized interview questions using Gemini AI based on your resume and selected role.

* 📄 **Resume Analyzer**
  Extracts skills, technologies, projects, and experience automatically from uploaded resumes.

* 🎤 **Mock Interview Practice**
  Practice real interview scenarios with timed questions and voice/video responses.

* 🧠 **Communication Skills Enhancer**
  Analyze confidence, fluency, clarity, and filler words to improve speaking skills.

* 📊 **ATS Resume Score Checker**
  Evaluate resume quality with ATS scoring and keyword optimization suggestions.

* 🛣️ **Learning Roadmaps**
  Structured roadmaps for Frontend, Backend, DSA, AI/ML, and placement preparation.

* 🔥 **DSA Heatmap & XP System**
  Track consistency using streaks, XP points, deadlines, and coding heatmaps.

* 📈 **Performance Analytics**
  View interview progress, strengths, weak areas, and improvement trends.

## ⚙️ Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/ishayan06/Interview_platform.git
cd Interview_platform
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Setup environment variables

Create a `.env.local` file in the root directory:

```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_api_key
```

---

## ▶️ Run the project

### Development mode

```bash
npm run dev
```

Visit:

```bash
http://localhost:3000
```
